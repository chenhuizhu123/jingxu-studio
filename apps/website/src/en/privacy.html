Privacy in the development preview

Updated November 4, 2026. Commercial hosting and payments are not enabled.

Website

This website has no advertising trackers or third-party analytics scripts. Its interactive example runs in your browser. The pricing questionnaire creates a file you choose to download; it does not submit your answers. The hosting provider manages basic access logs.

Desktop and mobile

Projects, assets, task records and version history stay on the device by default. Flutter mobile does not require a Jingxu account or desktop connection. An optional desktop remote workspace uses the address and token you configure; share that token only with trusted devices and use HTTPS.

Your providers

When you use a configured model or video provider, necessary prompts, references, scripts and project context are sent directly to that provider. Its policies govern its handling of that data. Demo mode does not make online generation requests.

Credentials

Desktop encrypts API credentials and uses system-protected storage for its encryption key when available. Mobile uses device secure storage for API keys. Project packages exclude credentials. Development server keys are protected by local file permissions.

External tools

Connect only MCP services you trust. External execution requests require approval in the product. A tool may access the data you approve providing to it.

Export and deletion

You can export project asset packages. Deleting a project removes its records; the preview retains underlying source files that may be shared by project copies. Back up important projects before clearing the app’s local workspace or removing the app.

Before a commercial release

The operating entity, contact channel, retention periods and user-rights procedures still need to be established. This page describes the preview implementation, without claiming that commercial privacy review is complete.
