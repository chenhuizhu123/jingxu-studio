BEFORE YOUR FIRST SHOT

开始前，
你可能想知道。

镜序自己训练视频生成大模型吗？+

镜序专注制作编排、镜头返修与版本交付。生成能力来自你配置的服务商，已有素材也能导入项目继续制作。

能保证角色和场景始终一致吗？+

不能保证。角色与场景参考有助于约束生成方向；你仍需检查具体镜头。镜序帮助保留参考、定位修改范围和管理候选结果。

没有 API Key，也能体验吗？+

可以使用明确标注的演示素材，或导入自己的图片与视频，体验分镜、版本选择、返修记录和导出。在线生成需要配置有权限和额度的 Key。

手机会在本地生成和渲染视频吗？+

手机项目、素材、版本和剪辑导出在本机处理，无需镜序服务器或连接桌面。AI 生成请求直连用户配置的服务商，需要网络与 API Key；本地导出时请保持应用打开。

我的素材和 Key 会放在哪里？+

默认保存在当前设备。调用生成服务时，必要的提示词和参考素材会发送给你配置的服务商。Key 加密保存，不通过项目接口返回明文。
