隐私说明

更新于 2026 年 11 月 4 日。当前为开发预览，尚未提供正式商业托管服务。

官网

官网不包含广告追踪或第三方分析脚本。交互演示在浏览器本地执行。定价调研生成一个由你自行保存的文件，不将内容上传。托管服务的基础访问日志由托管方管理。

工作站与移动客户端

默认保存在当前设备，Flutter 手机端无需镜序账号或桌面连接。桌面可选连接自行管理的远程工作站；配对令牌具有访问该工作站项目的权限，仅向可信设备提供令牌，远程连接使用 HTTPS。

第三方生成服务与模型

调用你配置的模型或视频服务时，相关提示词、剧本、参考素材及必要的项目上下文会发送给该服务商。具体处理方式取决于你选择的服务商。未配置服务时不会发起在线生成。

凭据

服务 API Key 在工作站加密保存，项目和设置读取接口不返回明文。桌面版使用可用的系统安全存储保护加密密钥；手机使用系统安全存储保存 API Key。项目导出包不包含凭据。开发后端的本地密钥使用文件权限保护。

MCP

只有你配置并启用的 MCP 服务可被连接。外部工具执行请求需要在应用中确认。MCP 服务器及其工具可能接触你批准提供的数据，请仅启用信任的服务。

删除与导出

可导出项目素材包。项目删除移除项目记录；当前开发预览不会立即清理共享候选的底层文件，以免影响项目副本。完整删除本机数据前请备份工作站数据目录。

发布前事项

正式商业发布前需要补齐实际运营主体、联系渠道、保留期限与用户权利处理流程。本页说明当前实现，不构成已完成正式商业隐私审核的声明。
