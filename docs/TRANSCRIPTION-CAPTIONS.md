# 语音识别与时间轴字幕

桌面 0.1.4、Flutter 手机 0.1.5 开发预览。

## 使用

桌面设置新增“语音识别与字幕”：填写兼容服务基础地址、支持分段时间戳的模型 ID、可选语言和自己的 Key。不预设模型。镜头编辑先保存草稿，再打开“时间轴字幕”，确认识别范围、模型与费用提示后提交。图片镜头需要先选配音才能识别；没有音频也可以手动编排图片镜头字幕。

识别结果保存为候选。选择候选，试听、调整每段开始/结束秒数与文字，点击“应用时间轴字幕”。时间从当前镜头起点算起。保留原剧本对白；空时间轴表示这个镜头不显示字幕。“切回台词字幕”恢复按镜头时长显示对白的方式。

字幕绑定素材 ID、裁切起点和镜头时长。选定配音优先于视频原音，配音从零开始；视频原音遵循镜头裁切。不发送背景音乐。更换音轨或改变这段范围后，旧字幕保留为过期内容；导出会要求重新核对或切回台词字幕，不自动套用旧时间。

手机镜头页的“时间轴字幕”可手动创建、修改或清除，也可编辑桌面识别后随项目包迁移的结果。保存和校验状态固定在底部。手机在线 ASR 提交尚未接入；手机原生字幕渲染仍需真机验收。

## 识别适配

协议核对来源：[OpenAI 官方 Create transcription](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)，2026-11-05。通用适配器向用户配置的 `{base}/audio/transcriptions` 发送 multipart，包含真实 WAV 文件、模型、`response_format=verbose_json`、`timestamp_granularities[]=segment` 和可选语言。模型必须返回带 `start/end/text` 的 segments；纯文本或不支持时间戳的接口不会被当作对齐成功。不推荐或预设某个服务商当前模型。

用已有 FFmpeg 从镜头实际使用的音轨取片段，转为 16 kHz 单声道 WAV，按成片行为裁切/补静音，最多 30 秒、2 MB。请求超时 120 秒，禁止重定向，响应上限 2 MB、最多 300 段。检查有限数值、段顺序、重叠和镜头范围；只校正最多 50 ms 的微小重叠与最多 100 ms 的边界舍入，其他异常拒绝。

Key 和配置快照在本机凭据体系中加密保存，不放入项目包或任务公开数据，不回显服务商错误正文。取消/关闭停止本地等待；已提交状态未知时不自动重发，人工重建可能再次收费。识别候选不会自动覆盖已应用的字幕。

## 交付与迁移

SRT 按镜头顺序累加每段时间。桌面 FFmpeg 烧录和手机 ImageLayer 使用分段起止时间；旧项目无时间轴时保留原有对白字幕。视频导出保存自己的 SRT，桌面导出记录提供签名链接，手机提供对应文件分享；更改当前项目不会替换旧成片的字幕。

含时间轴字幕的 ZIP 使用 **v2**，旧客户端明确拒绝，避免静默丢掉新字段。无时间轴仍输出 v1；新版接受 v1/v2。素材 ID 在跨端恢复时重新映射，字幕引用随之更新。过期字幕项目仍可备份，生成的当前 SRT 在过期时不附带；已有成片及它原来保存的字幕继续保留。

## 实际验证

- Node 完整 202 项通过；本轮含 14 项识别/模型/真实媒体用例、9 项时间轴 UI 用例和 1 项按导出版本下载 SRT 的用例。语句 87.43%、分支 76.83%、函数 83.33%、行 89.66%，覆盖范围是核心与 API。
- 从 6 秒双音调视频裁切后上传，检查实际 WAV 时长与频率；换配音后检查上传的是配音。验证 MP4 在字幕段之前/期间的真实帧变化、SRT 时间、临时文件清理、配置快照、取消/中断、异常响应、签名访问和旧成片 SRT 不随项目改变。
- Flutter 完整 77 通过、1 专用互操作用例默认跳过；静态分析无问题。新增 5 项字幕数据/ZIP 用例与 5 项组件用例，覆盖重排偏移、空轨、过期阻断、异常时间、v2/ID 引用、保存/刷新重试和删除行保留内容。
- 专用 `npm run test:interop` 实际执行两阶段，通过真实 PNG/MP4/WAV/SRT 与 v2 字幕数据的双向往返，比较来源引用、时间、文字及媒体字节。
- 22 张 Flutter goldens 包含中英字幕编辑页。是组件渲染，音频播放器测试使用可控控制器，不是系统截图。

测试服务给出确定的字幕；没有真实供应商识别额度，不能据此保证真实中英文识别准确率、词级对齐、说话人识别、翻译或口型同步。原生平台播放/渲染、浏览器/Electron GUI、Windows 安装仍未完成验收。
