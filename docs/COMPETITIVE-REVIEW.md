# 同类产品与改进验收

## 2026-11-06 桌面试点补充

- LTX Studio 的公开计划包含分镜、角色元素和按额度生成。Runway 同样把计划与生成额度挂钩。镜序试点优先验证桌面工作流的付费价值，费用边界由软件授权和用户自带模型服务各自说明。 [LTX Studio 价格](https://website.ltx.studio/studio/pricing) · [Runway 价格](https://runway.com/pricing)
- CapCut 的自动字幕说明覆盖桌面与手机，并提供编辑能力。镜序这轮优先让桌面用户在渲染前看到字幕来源变化和缺素材的具体镜头，保留每个成片修订的字幕文件。待真实用户用同一段带声素材对照操作步骤和校对用时。 [CapCut 字幕说明](https://www.capcut.com/help/how-to-recognise-subtitles)
- 试点优先测试多集短剧团队的两个场景。用同一项目测量单镜换候选时其他镜头保持原选择的效果，再把整季工程迁移到独立工作区，核对修订、素材、字幕和集号。试点报价等真实反馈后确定。 [本地验收](VALIDATION.md) · [桌面试点](DESKTOP-PILOT.md)

## 优先级

1. **P0，创作者能独立交付**：桌面和 Flutter 手机独立本地项目；BYOK 直连；断网可编辑；候选不覆盖；排序及裁切；MP4/SRT/素材包；中英文；导出失败明确；密钥不出现在项目分享包。验收：无账号、无镜序服务器依赖，从新建到导出完成一条真实链路。
2. **P1，降低返工**：参考与候选并列比较、检查结果绑定具体版本、切换素材使旧检查失效；只重做不合格镜头；保存生成时的参数；已提交的远端任务重启后继续查询，未知提交结果先核对以免重复付费。验收：改动其他镜头及重启后，已确认镜头的素材和选择保持稳定。
3. **P1，声音和字幕**：增加用户配置的 ASR/TTS 服务适配，字幕时间可修改、导出后对齐验证；字幕安全区、音量与音乐试听。验收：中英文各一段真实配音，与导出字幕逐句核对。当前镜头时间字幕不满足这个验收。
4. **P2，规模化**：集/场景层级、模板、营销钩子变体、批量多比例输出、跨设备可移植项目包及恢复、用量与成本记录。必须使用服务商实际返回价格或用户配置单价；不猜测费用。
5. **P2，发布闭环**：移动系统分享、正式渠道 API / MCP 发布工具、上传结果及重试；账号授权与发布确认。浏览器自动化是受控工具，不能保证所有平台无限制自动发布。

## 值得验证的差异化假设

- 本地保存、模型直连、可移植项目、可查看的用量，是否能让小型工作室更愿意购买软件许可？这不代表竞品均不具备这些能力。
- 候选、参考、审查意见和生成参数在同一个镜头内，是否能缩短选择与返修时间？用相同剧本对照工作流计时，而非只比较功能数量。
- 手机能独立编辑和导出，是否比强制连接工作站更容易上手？以首次成功导出、步骤数、崩溃和数据丢失为指标。

## 测试和发布门槛

记录首个项目完成率、首次导出时间、单镜返修时间、重启恢复、字幕偏移、导出成功率；真实生成的连续性由创作者盲评。覆盖中文/英文、Android/iOS 和 macOS/Windows。Mock、编译成功、官方产品文案不能证明设备体验或生成质量。当前没有真实用户付费验证，也没有完成竞品付费端到端实测。

每轮对比必须落成：来源与日期 → 具体缺口 → 实现任务 → 自动测试/人工验收 → 已完成或待验证状态。未通过的项目保留在差距栏，不列为已上线优势。
