# 镜序 Studio：交付标准

目标：可用于短剧及营销短视频的官网、macOS/Windows 桌面工作台，以及 Android/iOS 手机客户端。用户付费意愿必须通过真实访谈、试用和交易验证，不能以功能完成替代。

## 产品范围

- 国际化（用户明确追加）：官网、桌面端、Flutter Android/iOS 支持完整中文与英文界面；跟随系统并可手动切换；使用翻译资源；日期与状态提示本地化；用户创作内容保持原文；两种语言均有测试。
- 官网：价值主张、真实交互演示、工作流程、定价说明、下载与版本状态、隐私及使用条款。
- 桌面：项目与脚本、可编辑分镜、角色/场景参考资产、镜头候选版本与选择、任务队列、可取消生成、重启恢复、质量检查、字幕、真实 MP4 和素材包导出。
- Agent：内置营销/短剧 Skills、可配置模型、工具调用、外部 MCP 服务发现与执行确认；浏览器通过 MCP 接入。
- 集成：用户自带 Key；真实服务请求与轮询；断网、超时、失败和取消有真实状态。演示素材明确标记，不伪装在线 AI 生成。
- 数据：本地持久化、备份恢复、密钥保护、项目隔离、日志脱敏。
- 商业化：价格与许可边界明确；没有有效支付配置时不展示可用支付；不伪造付费用户、评价或下载。
- 分发：macOS 和 Windows 构建配置、原生平台 CI、安装包和真实验证记录；未签名或未实测的状态明确披露。
- 手机端（Flutter）：Android/iOS 共用 Dart 代码，本机 SQLite 项目与队列、本机素材与版本、安全存储用户 Key、BYOK 直连、原生本地剪辑导出、系统分享。无账号可用，不要求镜序服务器或桌面配对。重启后已知远端任务继续查询，提交结果未知时提示先核对服务商记录。后台执行受手机系统限制，本地导出时需保持应用打开。原 Capacitor 方案已由 Flutter 替换。
- 竞品优化：见 [对比与验收](COMPETITIVE-REVIEW.md)；以有来源的能力对照驱动改进，未验证的优势不用于宣传。

## 验证

单元测试覆盖脚本拆镜、版本选择、状态机、校验、字幕和导出；集成测试覆盖 API、持久化、生成服务模拟、失败与恢复、MCP；浏览器端到端覆盖创建、编辑、上传、生成、版本、任务、导出、设置；Electron 测试覆盖沙箱窗口和完整本地链路。生成质量、跨平台安装和付费意愿分别记录外部验证，不用 mock 测试证明。
