# 镜序 Studio 用户手册

适用版本为桌面 0.1.10 和手机 0.1.6 开发预览。桌面支持 macOS 和 Windows，手机有 Android 和 iOS 预览构建。安装包、系统要求、签名及验收状态以版本交付页为准。桌面端提供 14 天本机试用，可用授权码激活；在线结账即将开通，拿到授权码后可在应用内直接激活。使用自带 API Key 进行在线生成时，模型费用由服务商收取。 [客户端安装和版本状态](CLIENT-PREVIEWS.md)

## 先导出一支短片

### 桌面

1. 打开镜序，在创作工作台选择「打开试用工程」。示例《雨夜来信》已经选好素材，使用本地插画，可离线试用。
2. 进入「交付中心」。在「成片准备」查看就绪镜头数。选择「渲染成片」，等待「成片已就绪」。
3. 在「导出记录」下载 MP4 和同一修订的 `SRT · R…`。播放 MP4 检查画面和字幕，SRT 可在剪辑器中独立编辑。
4. 进入「所有项目」，从「新建项目」开始自己的作品，或先复制试用项目再练习修改。

### 手机

1. 在「项目」中选择「打开示例故事」，或用「创建项目」填写名称、画幅和剧本。
2. 进入「分镜」，点开镜头查看候选、剪辑和声音。也可以在项目列表右上角「导入项目包」，打开从桌面导出的单集工程。
3. 素材选齐后进入「交付」，选择「渲染 MP4」。保持应用在前台。完成后在「导出记录」选择「保存 / 分享」，按系统面板保存到文件或分享给其他应用。

## 试用与授权（桌面端）

镜序桌面端采用「本机试用 + 授权码激活」，不需要注册账号，授权信息只保存在你的工作站。

- **开始试用**。首次打开「打开试用工程」即开始 14 天本机试用；也可以在「设置与连接 → 授权与试用」中手动开始。试用期从第一次开始起按自然时间连续计算，卸载重装或回拨系统时钟都不会延长。
- **试用范围**。试用期内全部生成功能可用：视频候选、图片与首帧、台词配音、语音识别。试用到期后，这些生成操作会被停止并提示激活；**项目查看、镜头剪辑、字幕编辑、成片渲染与 MP4/SRT/工程包导出始终可用**，已完成的作品不会被锁。
- **激活授权**。在「设置与连接 → 授权与试用」的授权码输入框粘贴授权码，选择「激活授权」。激活后卡片显示授权邮箱、套餐、有效期、设备绑定和激活时间。`JX1-` 开头的授权码在本机离线校验，立即生效；在线商店购买的授权码在结账成功后出现在确认页并发送到购买邮箱。
- **设备与解绑**。授权码可能标注设备名额或绑定本机。换电脑前可在卡片中「解除本机授权」释放名额；解绑后本机生成功能停用，作品仍可查看导出。永久授权没有有效期，限期授权在卡片显示到期日。
- **提醒方式**。试用最后 3 天顶部出现浅色提醒条；到期后提醒条变为「立即激活」。任何生成被停止时都会给出中文原因，可按提示回到授权卡片处理。

许可数据保存在工作区数据根目录（试用记录 `.trial.json`、本机许可 `.license.json`、设备标识 `.machine-id`，在线授权另存 `license.json`），删除数据根会使试用重新开始，但也会离开当前工作区，请通过工程包迁移作品而不是删除目录。

## 剧本、分镜和候选

- **建项目**。选择 `16:9` 横屏、`9:16` 竖屏或 `1:1` 方形。将一个动作或一句对白写成一段，拆镜后补场景、景别和动作。已有候选的项目要大改剧本时，先建副本。
- **加素材**。桌面从「参考资产」导入图片、视频或音频。手机从项目的「素材」导入。桌面镜头内也可直接导入。镜头候选使用图片或 MP4，配音和背景音乐使用音频。在「候选版本」点击「选用」，让素材参与渲染。
- **绑定参考**。从「角色与场景」添加角色并绑定定妆图，在镜头中勾选相关角色和参考图。参考图可进入生成请求，角色连续性仍要逐镜检查。
- **只返修有问题的镜头**。在检查器填写返修要求，保存后生成新候选。旧候选及当前选用版会保留。比较并选用合适版本，更新审核状态，然后回到全片预览核对衔接。
- **调整剪辑**。在分镜中修改镜头顺序、时长和视频裁切起点。更换素材、修改音轨或调整裁切后，重新核对绑定旧来源的时间轴字幕。

## 配置在线生成

在桌面「设置与连接」或手机「设置」选择服务类型，填写服务地址、模型 ID 和对应 API Key。保存后先试一个短镜头。视频、图片、配音、桌面语音识别和导演助手可能需要各自的模型配置。Key 已保存时，设置页的密码输入通常留空，留空保存会保留现有 Key。

| 操作               | 在哪里完成                 | 提交前核对                                                       |
| ------------------ | -------------------------- | ---------------------------------------------------------------- |
| 视频候选           | 镜头检查器的「生成候选」   | 提示词、画幅、时长、参考图、服务商和额度                         |
| 图片候选和首帧视频 | 镜头的图片生成与首帧工作流 | 核对实际发送的参考和提示词。选中满意的图片后再确认提交首帧视频   |
| 台词配音           | 镜头配音区域               | 选择声音，核对台词和服务地址。完成后试听，再应用到镜头           |
| 语音识别           | 桌面的「时间轴字幕」       | 核对使用配音还是源视频音轨，以及当前裁切区间                     |
| 导演助手           | 项目的导演助手或高级工具   | 说明要改的镜头和约束。查看拟执行的外部工具及参数，再决定是否批准 |

在线任务在任务队列中显示进度。队列页会把**进行中（排队/执行中）的任务固定在最顶部**，带实时进度条与「取消」按钮，侧边栏角标显示进行中数量；其下是用量与成本总览，再往下是历史任务（成功/失败/已取消，可对失败任务「重新创建」）。取消通常停止本机跟踪，服务商可能继续处理和计费。遇到「提交结果未知」时，先查服务商后台的任务和账单，再决定是否重新提交。用演示模式可离线验证候选选择、裁切和交付流程。

### 让导演助手按你的方法工作（Skills）

「创作 Skills」页把可复用的创作标准与验收流程写成 Skill（内置若干，也可新建自定义）。内置 Skill 与你自建的 Skill 都以**可读名称**展示（如「短剧分镜导演」「逐镜返修」「营销多版本对比」）。新建自定义 Skill 时需填两项：**名称**（界面显示的可读名，如「品牌视频审查」）和**标识**（仅内部使用的英文小写+连字符，如 `brand-video-review`，也是导演助手调用时的稳定 ID），再写用途说明与操作流程/验收标准即可；保存后表单会清空，可继续新建。点开任一 Skill 卡片查看完整规则后，可直接点**「用这个 Skill 询问导演助手」**，会跳到当前作品并打开导演助手、自动预选该 Skill（移动端同样会展开助手面板；没有打开的作品时会提示先新建）。在项目里打开导演助手，输入框上方的下拉默认是**「不指定 · 通用导演助手」**——此时助手通读项目后给通用建议，不会强套某个特定流程；下拉下方会实时显示当前所选 Skill 的用途说明。需要按固定方法执行时（如逐镜返修、品牌规范检查），从下拉选中对应 Skill 再发消息，该 Skill 的规则就会作为本次指导依据。Skill 只影响助手的建议与工具使用方式，不改变数据，外部工具执行仍需你逐条批准。

导演助手用的是你自带的**对话模型**，和视频/图片生成服务是**分开配置**的。若还没在「设置与连接 → 导演助手模型」填好服务地址、模型 ID 和 API Key，打开助手时顶部会直接出现「还没有配置导演助手模型」的引导卡，点**「去配置模型」**即可跳转到设置（移动端会同时收起助手面板），此时发送键禁用、不会发出注定失败的请求；三项配置齐全后引导卡消失、恢复正常发送。

## 声音、字幕和交付

1. **先确定音轨**。为镜头选择配音时，成片使用该配音。否则保留源视频音轨。背景音乐在交付页单独设置音量。试听配音是否完整，尤其留意镜头短于音频时的截断。
2. **再定字幕**。桌面可以识别当前音轨，校正分段时间和文本后应用。手机可编辑或导入已有的时间轴字幕。没有应用时间轴时，成片使用镜头台词。对齐失败时可重审时间轴，或在字幕编辑器明确切回台词字幕。
3. **修复交付阻塞**。桌面「成片准备」会列出缺少已选素材或字幕待核对的镜头。点击对应行即可返回镜头。补齐后回「交付中心」，就绪计数随项目更新。
4. **选择交付格式**。勾选「将字幕烧录到画面中」可让字幕随 MP4 显示。成片仍有对应的独立 SRT。「字幕与分镜」中的 SRT 和 CSV 按当前项目生成，交付历史成片时应使用该记录旁的 `SRT · R…`。
5. **核对实际文件**。打开下载的 MP4，检查画幅、片长、音乐、语音、字幕和场景衔接。项目修改后重新渲染，按修订号选取成片和配套字幕。

## 生成前先看免费预演片

在为几十个镜头付费生成视频之前，先用**免费预演**判断整场戏的节奏与连贯。进入「交付中心」，在「免费预演」卡片选择「生成免费预演片」：

- 它把每个镜头**已选的图片或参考图**按镜头时长串成一条带字幕的预演片；还没有素材的镜头会用标注了镜头号与标题的占位卡代替，因此**不要求素材就绪**，刚拆完分镜就能用。
- 全程在本机用内置渲染器合成，**不调用任何模型、不产生任何服务商费用**，也不占用试用或授权额度；预演任务不计入 AI 用量。
- 预演片为静音（对白以字幕呈现），适合快速核对镜头顺序、单镜时长、叙事节奏和转场连贯。发现节奏问题就回分镜调整时长或顺序，满意后再批量生成正式视频，把钱花在值得的镜头上。

预演完成后出现在「导出记录」中，带「预演」角标，文件名含 `animatic`，可下载 MP4 与对应 SRT；它与正式成片分开保存、互不影响，可重复生成。

## 查看本项目 AI 用量

桌面「交付中心」的「本项目 AI 用量」按**成功**的在线任务统计你自己模型服务的调用量：视频生成（秒）、图片生成（张）、配音合成（字）、语音识别（秒），并标注每类的成功任务次数。失败、取消、进行中的任务和本地 MP4 渲染不计入。费用由服务商直接收取，用量数据只保存在本机，用于你在服务商后台对账。

### 按你自己的单价估算成本

用量卡上点「设置单价」，把服务商账单上的单价填进去（视频/语音识别按每秒、图片按每张、配音按每千字符，可自定义货币符号），卡片就会显示每类用量的估算金额和「估算合计」。单价是你自己填写的数据，镜序不内置、不猜测任何模型价格；没填单价的类别不估价，合计只累加已填的类别。它只用于和服务商账单对账，不是镜序的收费；清空单价即可取消估算。

### 全工作区用量月报与 CSV 对账

「任务队列」页顶部是「用量与成本总览」：按**本月 / 近 30 天 / 全部**切换时间范围，汇总该范围内所有项目的成功任务，显示各类用量、估算合计和分项目明细表（已删除的项目会标注「项目已删除」，历史用量仍可追溯）。点「导出 CSV」可下载带 BOM 的 UTF-8 表格（Excel 直接打开不乱码），每行一个项目、末行为合计，方便按月与服务商账单核对，或作为给客户报价、核算单集成本的依据。总览卡上点「设置单价」可直接维护单价（与交付中心是同一份设置，任一处修改全局生效）；未填写时只统计用量、不显示金额。

在「设置单价」里还可以填写可选的**月度预算**（与单价同一货币）。切到「本月」时，总览会显示预算进度条：未到 80% 为绿色、达到 80% 变黄色提醒留意花费、达到或超过预算变红色并显示超出金额（如预算 ¥5、已用 ≈¥260，显示「已超出 ¥255（100%）」）。预算只是本地的花费护栏与提醒，**不会阻止任何生成任务**，也不是镜序收费；只有配置了至少一类单价、能估算出金额时才会显示。

### 批量生成前先看花费

分镜工作台点「批量生成」不会立刻扣费入队，而是先弹出确认：本次要生成多少个镜头、合计多少秒；如果你已填写视频每秒单价，会显示**预计视频成本 ≈ 金额**，并提示重做或多版候选会再次计费、实际以服务商账单为准。尚未确认的镜头优先生成，已确认镜头不受影响；所有镜头都已有候选时会明确提示本次将全部重新生成。演示模式下显示「不消耗额度」，未设置单价时可直接继续，也可以先去总览补单价。确认后任务才加入队列，取消不产生任何费用。

如果你设置了**月度预算**，确认框还会把「本月已用估算 + 本批预计成本」合并预判：达到预算 80% 时黄色提示「将接近月度预算」，达到或超过时红色提示「将超出月度预算」，并列出本批后估算支出、预算与超出（或剩余）金额。这与总览的预算进度条是同一份本地护栏，**只提醒、不阻断**——确认按钮始终可用，是否继续由你决定；演示模式不显示该提醒。

右侧镜头检查器的「生成候选」按钮上方也会显示该镜头的单行预估（如 **≈ ¥4 · 2 秒**），随你修改镜头时长实时变化，鼠标悬停可见「以服务商账单为准」说明；演示模式或未设单价时不显示金额。

「生成图片候选」和「用首帧生成视频」的确认弹窗顶部同样有**预计成本**条：图片按每张单价（如 **≈ ¥0.5 · 1 张**），首帧视频按时长与每秒单价（如 **≈ ¥8 · 4 秒**），并注明以服务商账单为准；未设对应单价或演示模式时不显示金额，只保留"可能产生费用"的提示。

镜头检查器「生成台词配音」的确认面板会统计台词字数，已配置配音每千字符单价时显示 **≈ 金额 · N 字**（如 7 字 × ¥4/千字符 ≈ **¥0.028**），未配置时只显示字数。

「时间轴字幕 → 识别当前音轨」的确认面板按本镜头实际发送的音频秒数（仅配音/源视频音轨片段，不含背景音乐）估算：已配置识别每秒单价时显示 **≈ 金额 · N 秒**（如 2 秒 × ¥0.2 ≈ **¥0.4**），未配置时只显示秒数。

## 多集制作和跨设备迁移

桌面「所有项目」可导入多集剧本。用「第 1 集」或 `Episode 1` 等编号标记分集。预览中核对每集的开场、结尾和镜头数，然后确认导入。后续可追加集数。角色定妆与同名场景参考可从镜头或角色的同步入口预览影响范围，再应用到其他分集。

| 目的             | 操作                                                                                        | 拿到什么                                                                |
| ---------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 给客户交成片     | 从交付中心下载某一修订的 MP4 和 SRT                                                         | 播放文件和可编辑字幕                                                    |
| 一次交付多集     | 在桌面剧集内「批量渲染就绪集」后下载交付 ZIP                                                | 已导出分集各自最新的 MP4、对应 SRT 及缺失集数清单。提交前核对集数和修订 |
| 单集换设备或备份 | 桌面「交付中心」→「打包素材」后下载 ZIP。手机在交付页打包并保存，再从目标设备「导入项目包」 | 可继续编辑的独立项目副本。包含素材、角色、候选和剪辑                    |
| 整季换电脑       | 在剧集卡片选择「导出整季工程」，目标电脑从「所有项目」选择「恢复整季工程」                  | 独立的整季副本，保留原集号。整季迁移使用桌面端                          |

工程包会包含你选择保留的项目内容及媒体。分享前检查剧本、参考图片、声音和成片是否适合接收方。API Key 与外部工具授权需要在目标设备单独配置。含时间轴字幕的项目使用较新的包格式，旧客户端提示版本不支持时先更新。工程包上限 2 GiB，单个源素材上限 200 MiB。升级、换机或卸载前，先导出并试着恢复一次。

## 常见问题

| 现象                       | 怎么处理                                                                                        |
| -------------------------- | ----------------------------------------------------------------------------------------------- |
| 生成提示先开始试用或激活   | 打开「设置与连接 → 授权与试用」开始 14 天试用，或粘贴授权码激活。试用到期后作品仍可查看和导出。 |
| 渲染按钮不可用             | 桌面查看「成片准备」，给每个镜头选图或视频并复核过期字幕。手机先进入分镜逐个检查。              |
| 在线生成返回认证或额度错误 | 核对服务地址、模型 ID、Key 权限和可用余额。只提交一次短镜头验证配置。                           |
| 任务在重启后仍在等待       | 已知远端任务 ID 的任务可继续查询。提交状态不明时到供应商后台核对。                              |
| 下载链接过期               | 回到项目并刷新列表，再从该修订的导出记录下载。确认目标位置有可写权限和足够空间。                |
| 项目 ZIP 无法打开          | 确认选择的是镜序工程包，整季工程要用桌面恢复入口。保留原包，更新客户端并检查大小。              |
| 需要反馈故障               | 记录客户端版本、系统、发生时间、项目修订、镜头编号及任务错误。分享前移除密钥和未获授权的素材。  |
