# 台词配音 / Dialogue voiceover

桌面 0.1.3、Flutter 手机 0.1.4 开发预览。两端已接入用户配置的 Speech-compatible 服务；真实服务商配音质量与真机交互仍待验收。

## 使用路径

1. 在“设置与连接 → 台词配音服务”填写 API 基础地址、模型 ID、音色 ID、语速与自己的 Key。地址不包含 `/audio/speech`。不预设模型或要求镜序云账号。
2. 编辑镜头对白，点击“生成台词配音”，核对实际发送文本、模型、音色和语速，然后创建任务。准备提交时保存草稿；保存失败不发送生成请求。服务商可能收费。
3. 在任务队列查看真实状态与台词快照。完成后新增一个标记为 `AI Voiceover` 的 WAV 素材；在镜头配音下拉列表选它，试听并保存。原音频素材和已选音轨不被自动覆盖。
4. 音轨比镜头长时，试听区域提示成片将截断。可缩短台词、调整语速重新生成，或调整镜头时长。现有 MP4 渲染器会使用已选配音并混合背景音乐。

这是合成音轨，不是语音识别、逐词字幕或自动口型对齐。字幕仍按镜头时长排列，成片前要试听核对。

## 适配协议

用户配置的服务需接受 `POST {base}/audio/speech`，JSON 字段为 `model`、`voice`、`input`、`speed`、`response_format: "wav"`；Bearer Key 直连服务商。仅支持无内嵌凭据/查询参数的 HTTPS，回环测试/本地网关可使用 HTTP。重定向拒绝，防止 Key 被转交给其他地址。首版要求返回可解码 WAV 字节，不接受 URL 或 JSON 伪装成音频。

协议字段核对自 [OpenAI 官方 Speech API 文档](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)，2026-11-05。该页现已标注其现有 Speech 模型弃用安排；因此本产品不预设或推荐这些旧模型。这个通用适配器也不等于已支持新的 Realtime 音频协议。用户须选择服务商当前仍支持的兼容服务与模型；没有进行真实付费服务验收。

## 状态与数据

- 提交时保存台词、模型、音色、语速和加密 Key 快照；排队后更改配置不会改变已排队请求。最大 3000 字，不静默截断。
- 请求最多等待 120 秒；流式写入独立暂存文件，总量最多 32 MB。检查 WAV 文件头、实际音轨/时长，并使用现有 FFmpeg 完整解码检查后才发布素材。不会仅凭响应 MIME 宣称成功。
- 准备/执行中可从任务队列取消；本地停止不保证远端停止计费。中断或重启时若已进入提交而结果未知，不自动重发。人工“重新创建”使用当前保存的台词和设置，可能再次收费。
- 创建任务已成功、但刷新失败时，表单保留接受的任务 ID；重试只刷新，不再次提交。关闭界面不取消已经提交的任务。
- 失败清理临时音频；如果写入回执失败但项目已经引用文件，则保留该文件。启动只尝试清理严格命名的本产品未引用配音临时/遗留文件，保留其他音频、导入文件和已引用素材。
- API Key 不返回到界面、不进入项目 ZIP，错误不保存服务商返回正文。任务配置加密保存在本机凭据体系中。

## 验证

`tests/speech.test.ts` 使用本地 HTTP 协议服务与真实 FFmpeg WAV，覆盖请求快照、加密 Key、取消/中断、HTTP/JSON/损坏音频、过大声明/实际流、重定向、重复与过期请求、存储回执异常、旧配置、恢复和实际 MP4 音轨。合成测试音轨是正弦波，验证可解码且实际有能量，不是用测试音代替供应商发音质量验收。

`tests/speech-ui.test.tsx` 在内存 DOM 中验证中英确认、保存失败、刷新安全重试、取消、设置、音轨超时长提示。没有访问受限浏览器、Electron 窗口或 Simulator。

```sh
npx vitest run tests/speech.test.ts tests/speech-ui.test.tsx
npm run test:coverage
npm run build
```

真实中英文配音自然度、音色可用性、服务商额度/计费与平台 GUI 验收仍待完成。跨供应商使用相同字段不能保证相同效果或所有模型都兼容。

## Flutter 手机 0.1.4

镜头页 → 生成台词配音 → 核对文本与配置 → 确认并生成。脏草稿先保存；保存失败不进入生成页。服务设置包含地址、模型、音色、语速和 Key；原有设备配置缺少语音字段时自动补默认值，保存旧客户端配置保留已有语音 Key。

生成后在镜头配音列表选择音轨，使用本地播放器试听、暂停、重播与拖动。音轨长于镜头会明确提示成片截断。切换页面或进入后台暂停试听，销毁页面释放播放器。播放器复用 [just_audio 0.10.6 官方组件](https://pub.dev/packages/just_audio/versions/0.10.6)，通过本地文件播放，不使用代理上传音频。实际原生播放效果尚未通过设备验收。

手机请求同样流式写文件、32 MB 限制、120 秒等待和禁止重定向；使用现有 `http` 的 AbortableRequest 停止网络等待。暂存文件保留 `.wav` 扩展名，使用平台媒体探测检查后才发布；这与桌面的 FFmpeg 完整解码检查范围不同。取消原生探测只停止等待，不能强制停止底层平台方法。模型与 Key 的任务快照放入设备安全存储，项目与任务记录不保存 Key；语音任务结束或取消后清理任务凭据。

引擎关闭会停止语音请求并等待异步任务收尾，再关闭数据库；重复关闭共享同一次完成。修复了队列刚读到空结果时有新任务入队可能遗漏唤醒的问题。重启时提交状态未知的语音任务失败并提示核对，保留已引用素材，只清理严格命名的未引用配音文件。

新增 17 项引擎/API/迁移测试和 6 项组件测试；完整 Flutter 套件 67 通过、1 专用跨端用例默认跳过。使用真实 WAV 文件和本地 HTTP 服务验证请求、取消 header/stream 等待、Key 隔离、快照、过大/损坏响应、存储回执、队列唤醒和项目 ZIP 迁移；没有用平台录音或付费服务生成测试音。播放器组件测试使用可控控制器，验证 UI 消费状态与生命周期，不证明设备音频插件已执行通过。
