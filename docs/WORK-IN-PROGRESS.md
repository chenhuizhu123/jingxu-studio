# 当前实现接续

2026-11-05。桌面 0.1.9、手机 0.1.6 开发预览。设备、供应商和用户付费验证单列。

## 当前能力

官网中英文、私有部署、年轻的深色创作台视觉。发布源提交 `bb317bb40da214792b7453e1f85b08e8f14e0af8`，更新了桌面 0.1.9 和跨集场景参考说明。安装包通过工作区交付。

Electron 桌面与独立 Flutter 手机均本地保存项目，BYOK、生成队列、参考/角色/候选、排序裁切、配音/混音、字幕、成片与项目包。LangGraph/gray-matter 用于桌面 Agent/Skills，手机有自己的工具循环与 HTTP MCP；外部执行经确认，不自动重放中断的外部写入。

桌面 0.1.6 可预览、导入并追加多集剧本。支持中英文编号标题或按段落切分。分集预览显示开场、结尾和镜头数，确认后原子保存整批项目。各集按原编号切换和编辑，批量渲染仅提交就绪集。交付 ZIP 流式打包各集最新 MP4、对应 SRT 和缺失集号。桌面保留剧集分组，移动端可导入单集项目包。

桌面 0.1.7 可在同一剧集中预览并同步角色定妆图和人设。已有定妆图或自定义人设的分集需主动勾选。重名歧义和相关镜头正在生成的分集跳过。角色发生变更时，相关镜头回到待核对，历史候选可继续使用。并发完成的旧视觉检查会被拒绝。单集项目包携带定妆图与本集的角色引用。

桌面 0.1.8 支持将整季导出为可编辑的 ZIP，在独立工作区恢复剧集副本。保留原集号、剧本、候选、角色参考、成片和时间轴字幕。恢复先验证每集及素材，再原子写入。单包上限 2 GiB，最多 99 集及 15,000 个 ZIP 条目。手机端继续使用单集工程包。

桌面 0.1.9 可在分镜检查器添加本地参考图，并在同一剧集内预览、同步到其他集的同名场景。同步添加图片并保留已有参考、候选和选片；跳过生成中或参考已达上限的镜头。保存参考草稿前检查是否有外部更新。跨集入口在桌面，手机单集包格式沿用现有镜头参考字段。

桌面/手机已接入 Speech-compatible 台词配音；手机复用 just_audio 本地试听，路由退出与后台暂停。详见 VOICEOVER.md。

桌面 0.1.5 通过 Seedream 生成图片候选，预览精确提示词及去重后的镜头和角色参考。首帧视频经确认后将当前选中图片发送给 Seedance，画幅随首帧。候选保留原选择，配置和项目提交快照与任务绑定，提交中断不自动重放。复用现有 JPEG 素材、分镜版本和 ZIP 契约。

Flutter 0.1.6 接入相同的图片和首帧工作流。配置存设备安全存储，生成由客户端直连服务商。图片输入去重并限量，输出解码后入库，首帧视频按已确认图片与模型快照提交。已知远程 ID 在重启后续查，提交结果未知时提示核对服务商记录。中英文确认页和更新后的镜头页已留六张组件快照。

桌面 0.1.4 新增分段 ASR、实际音轨裁切、确认/候选、时间与文字编辑；手机 0.1.5 可编辑/导入时间轴并按段渲染。字幕绑定素材/裁切/时长，变化后保留过期内容并阻止误用。每条导出记录提供自己保存的 SRT，不从当前项目重建旧成片字幕。详见 TRANSCRIPTION-CAPTIONS.md。

含时间轴项目使用包格式 v2；无时间轴保留 v1。新版读 v1/v2，旧版明确拒绝 v2。真实 TypeScript → Dart → TypeScript 与反向 ZIP 往返检查了字幕来源 ID、时间、文字和 PNG/MP4/WAV/SRT 字节。
